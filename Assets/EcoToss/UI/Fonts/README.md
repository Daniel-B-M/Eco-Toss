# Nunito

Fuente de Google Fonts / The Nunito Project Authors, distribuida bajo SIL Open Font License 1.1 (Nunito-OFL.txt).
Origen: https://github.com/google/fonts/tree/main/ofl/nunito

Versiones estáticas derivadas de Nunito[wght].ttf: Regular (400) y ExtraBold (800), para compatibilidad con Unity.
MainMenu y Gameplay usan uGUI con textos TextMesh Pro y los recursos SDF dinámicos generados con Unity 6000.3.16f1. La variante Regular de TMP enlaza ExtraBold para negritas. El HUD OnGUI de Gameplay 2 recibe Nunito Regular desde el Inspector.

Los SDF conservan los TTF de origen y generan su atlas dinámicamente, incluidos acentos y ñ.
